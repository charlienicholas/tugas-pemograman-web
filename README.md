## 📋 Ketentuan Teknis Pengerjaan

1. **HTML5 Semantik (`index.html`):**
   * Validasi dokumen HTML5 lengkap (`<!DOCTYPE html>`).
   * Menggunakan elemen semantik secara presisi: `<header>`, `<nav>`, `<main>`, `<section>`, dan `<footer>`.
   * Bagian utama meliputi:
     * **Beranda (Home):** Perkenalan interaktif, status server, metrik, dan foto profil (`images/profile.jpg`).
     * **Tentang Saya & Pendidikan (About & Education):** Latar belakang dari SMK Negeri 9 Medan hingga Politeknik Negeri Medan.
     * **Keterampilan / Loadout (Skills):** Daftar keahlian teknis (HTML, CSS, JS, PHP, C++, Java, Git) dengan sistem *rarity* dan *level*.
     * **Proyek / Game Showcase (Projects):** Daftar portofolio pilihan yang dilengkapi dengan carousel murni CSS.
     * **Kontak & GitHub Link (Comms):** Informasi kontak, tautan sosial media, dan akses repositori langsung.

2. **CSS3 Eksternal (`style.css`):**
   * File terpisah (`style.css`) dengan tata letak modern menggunakan **CSS Flexbox** dan **CSS Grid**.
   * Estetika neon arcade retro-futuristik dengan mode gelap (`#07070f`), animasi kubus 3D, efek CRT scanline, dan transisi halus.
   * *Responsive Design* sempurna (mulai dari layar mobile 320px hingga desktop 4K).

3. **Batasan & Standar Kepatuhan:**
   * **Tanpa JavaScript** (seluruh interaktivitas menggunakan fitur CSS murni seperti *radio button hack* untuk carousel).
   * **Tanpa Framework CSS** (murni CSS3 tanpa Bootstrap, Tailwind, atau preprocessor eksternal).
   * **Tanpa Backend Server** (dapat dijalankan secara instan dengan membuka file `index.html` di browser).

## 🚀 Cara Menjalankan Proyek

1. Kloning repositori ini ke perangkat Anda:
   ```bash
   git clone https://github.com/charlienicholas/tugas-pemograman-web.git
   ```
2. Buka folder proyek.
3. Klik dua kali atau buka file `index.html` menggunakan browser web apa saja (Chrome, Firefox, Edge, Safari).
